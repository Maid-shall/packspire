# シームレス遠征戦闘 UI仕様

更新日: 2026-08-16

## 視覚基準

- 最上位ブランド基準: 現行ホーム画面の黒革、生成紙、古金、封蝋、青緑の配達印。
- 承認済み構図: 2026-08-16にユーザーが承認した、左チェーン式リールと右下の独立山札・捨札を持つ戦闘UI案。
- 主役: 手札と戦場。情報枠は人物と操作を補助し、画面外枠として競合しない。
- 静かな領域: 戦場中央と上空を空け、HUDを人物付近と画面下へ限定する。

## 動的状態

- HP、ブロック、エネルギー、山札、捨札、時系列行動、状態異常はC#から内容と意味クラスだけを更新する。
- HPは`ProgressBar`ではなく専用のtrack/fill要素を使い、C#がfill幅だけを百分率で更新する。
- ブロック0の人物には防御表現を表示しない。ブロック中は体力票を青く覆わず、右端から離した独立の青い盾印と防御値だけを表示する。
- 左端には上側が未来、下側の`NOW`が予兆開始点となるチェーン式縦リールを置く。
- リールの可視範囲は直近10戦闘秒とする。画面内の行動数は固定せず、敵の行動間隔に応じて空白と密集がそのまま現れる。
- 内部では表示範囲に約3秒の確定余白を加えた分だけ行動票を先行生成する。それより先は具体的な票を確定せず、次の行動パターンを選べる状態として保持する。
- 敵行動は単発補充ではなく、行動間隔と休止時間を含むパターン単位で生成する。解決済み行動の数を基準に画面内を埋め直さない。
- パターン選択と時刻実行は分離する。現在の番人は順番固定の選択戦略を使うが、敵ごとの選択戦略からHP、段階、クールダウン、直前パターンを見て次の一まとまりを変更できる構造とする。
- 行動パターンは`RealtimeEnemyTimelineProfile`のScriptableObjectへ保存し、表示用C#へ秒数や技列を直書きしない。旧ターン制の`EnemyContent.moves`とは移行完了まで分離する。
- 行動種別は文字列の接頭辞では判定せず、`RealtimeEnemyActionKind`を予定作成、予兆、解決、表示まで保持する。`actionId`は表示名とログ用途に限定する。
- 行動票はすべて同寸の白い生成紙とし、全票を一本の鎖と同一pixel/secで移動する。空白時間には札を表示せず、背景と鎖だけを見せる。
- 行動票は78論理pxの高さとし、装飾済み生成紙へ「行動別の薄墨姿絵／大きな共通印／右寄せの効果値」を置く。行動名や説明文、`ENERGY`などの英字ラベルは置かない。
- 行動印は敵や武器に依存しない共通紋章とし、攻撃は赤、防御は青、エナジー補給は緑とする。効果値は通常フォントではなく専用のかすれた活版数字アトラスを右端へ大きく置き、右端をわずかに見切れさせる。連撃回数は効果値へ結合せず、束ね帯へ分離する。カード本体は全種で白い生成紙に統一する。
- エナジー補給は別レールに置かず、敵行動と同じ10枠内を同じ時間尺度で移動させる。これにより、カード使用前に回復と敵行動の前後関係を比較できるようにする。
- エナジーと手札補充は大判行動票を使わず、鎖から伸びる細い色付き罫線として表示する。罫線中央にエナジー印または札束印を置き、緑／円形と青／札形の双方で識別する。
- 同時補給は同一時刻の1本の罫線上へ両方の印を並べ、各印の右へ`+1`または`×N`を表示する。敵行動票の視覚優先度を越えない。
- 実行点への接近では票の色を変更しない。連続した位置だけで現在性を示す。
- 敵の予兆モーションは行動票が`NOW`へ触れた時に開始し、票は同じ太さのまま`NOW`より下へ流れて画面外へ退場する。
- 敵の防御値は青い盾印に分離し、攻撃セルと同じ記号や同じ枠を流用しない。
- 状態異常は最大5件を印章チップとして生成し、詳細はtooltipへ表示する。
- 山札・捨札は各ボタンから一覧オーバーレイを開く。戦闘中の入力受付中のみ使用可能。
- 一覧表示中はカード使用と戦闘時間を停止する。
- 手札は1〜10枚で共有扇配置を使い、7枚以上では重なり量を増やす。
- カードはエナジーがあれば任意の時点で使用できる。スキルボタンとターン終了ボタンは置かない。
- 3体表示は構図検査用。実戦の複数対象選択は別工程とする。

## 行動票・連撃の確定仕様（2026-08-17）

- 全行動票は同寸の装飾済み生成紙とし、左寄りに行動別の薄墨姿絵、中央に共通印、右端に効果値を置く。
- 票上の文字情報は効果値だけとし、行動名を重ねない。薄墨姿絵は主役ではなく敵と行動姿勢を識別する濃度に抑える。
- 連撃は効果値に1打分の値だけを表示し、同じ移動要素の中で右下へずらした複数枚の紙と、赤・生成り・赤の縦帯で束を示す。回数は帯の生成り部分へ小さく置く。例: 右端に`4`、帯に`3`。
- 空白時間は票を置かず、リール背景と一本の鎖だけを見せる。
- 現在位置はリール左から突き出す紙製の`NOW`矢印票で示し、下部操作UIと重ならない高さへ固定する。
