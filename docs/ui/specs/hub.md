# ホーム画面仕様

## 基準

- 論理解像度: `1280x720`
- 1920x1080表示時の換算倍率: `1.5`
- 視覚基準: `docs/concepts/art-direction-candidates-2026-07/03-obsidian-misprint.png`
- 実装資料: `docs/ui/references/hub/README.md`

## 再現受け入れ条件

参考画像は外周の黒縁を除いた16:9領域を`1280x720`へ正規化して比較する。
以下は意図的な仕様変更を除き、実画面で優先して一致させる条件とする。

- 左施設列は上広がりとし、斜め境界は上端`x=260`、下端`x=220`を通す。
- 「遠征」は施設列へ置かない。上から荷造り、保管庫、家宝、役職、図鑑の固定順とする。
- 通常施設は日本語名を主役とし、その下へ小アイコンと英字名を置く。大アイコンを日本語名の左へ置かない。
- 通常施設は高さ`82px`前後、選択中は高さ`116px`前後とし、隙間なく連続させる。幅は上から`252/248/244/240/236px`として斜線へ揃える。
- 施設名は低解像度の参考画像から切り抜かず、プロ向け明朝字形から縁取りなしで生成した施設別の透過ワードマークを使用する。通常高`42px`、選択中高`58px`を基準にする。
- 街路案内、装備記録、本日の記録、本日の指令、遠征準備も同じ生成規則の専用ワードマークを使用する。
- ワードマークは素材の縦横比を維持し、表示枠からの見切れ、引き伸ばし、隣接要素への越境を禁止する。
- 選択中の朱紙は左端`x=8`付近から始め、水色の紙ズレと右矢印を紙面と一体に見せる。
- マウスではホバーした施設が朱紙へ変わり、クリック・タップは1回で直接遷移する。
- 中央人物領域は`x=232〜704`、右資料欄は`x=704〜1264`を基準にする。
- 装備記録は正方形サムネイル一覧にせず、縦長の資料画を3列で見せる。
- 本日の記録は太い外箱ではなく、3本の横罫、左の記号、本文、右端の遷移表示で構成する。
- 本日の指令は`x=620〜1262`、高さ`190px`前後とし、右の遠征準備領域へ約48%を割り当てる。
- 指令紙の見出し、本文、補足値は同じ大きさにせず、参考画像と同じ3段階の文字階層を作る。

意図的な相違は、遠征メニューの削除、戦闘カード・占有形状の削除、現在の人物・術式・役職・家宝への動的連動に限定する。

## 画面契約

| 機能 | 表示 | 操作 |
|---|---|---|
| 主要施設 | 左の固定リスト | クリック・タップは1回で直接遷移。ホイール・上下入力では選択を移動し、決定入力で遷移 |
| 街路案内 | 左下の専用行 | モーダルを開き、分類して施設を選択 |
| 配送人 | 中央の透過立ち絵 | 現在選択中のキャラクターを表示 |
| 配達資料 | 右上 | 所持金、選択中人物の前後図、現在の術式・役職・家宝を表示 |
| 装備記録 | 右上の縦長3区画 | 術式・役職・家宝の現在値を大きなイラストと共に表示。操作は持たせない |
| 本日の記録 | 右下 | 現在状態から生成した最大3件を表示し、各記録票全体から関連画面へ遷移 |
| 本日の指令 | 下部の紙票 | 現在の目的地、荷造り、配置数を表示して遠征準備へ遷移 |
| 保管庫 / 図鑑 | 右下の索引 | 各画面へ遷移し、現在件数を表示 |

## 状態

- `is-locked`: 未解放施設。選択不可で低い不透明度にする。
- `is-reel-current`: 固定リスト内の決定候補。順序を変えず、その場で寸法を拡大し朱紙へ差し替える。
- `has-art`: 家宝記録に選択中装備の実画像がある。
- `is-open`: 街路案内モーダルを表示する。
- `ps-selected`: 街路案内の分類選択。

## 禁止事項

- カメラ、`PanelSettings`、ゲームビュー解像度をホーム実装から変更しない。
- 固定構造をC#で組み立てない。
- 見た目をC#のインラインスタイルで補正しない。
- ホームに戦闘カードと占有形状を置かない。遠征準備への入口は右下の指令票に集約する。
- 全画面生成画像や疑似文字を実装へ直接使用しない。
