## 失敗原因

| ID | 問題 | 原因 | 次回の必須対策 |
|---|---|---|---|
| VR-01 | 画面全体が過装飾 | 画像優先を画像多用と誤解 | 大領域ごとの装飾予算を決める |
| VR-02 | 素材の画風が不統一 | V3/V4/V5と共通素材を無検証で混在 | 領域ごとの素材キット許可表を作る |
| VR-03 | タブ内の紋章が重複 | 完成部品とアイコンを区別しなかった | 素材を完成部品・枠・アイコンへ分類する |
| VR-04 | 装備絵が四角く見える | 一覧用の背景付き画像を主役へ拡大 | 透明切り抜きまたは専用展示画像を用意する |
| VR-05 | 文字が小さく密集 | 1920座標を1280論理座標へ適切に換算しなかった | PanelSettings基準で論理寸法を書く |
| VR-06 | 背景と文字が競合 | 情報面の遮光と静かな面が不足 | 領域単位でコントラストを設計する |
| VR-07 | 完成前に全領域へ展開 | 実画面撮影を確認せず一括実装 | Gate Aから一領域ずつ撮影する |
