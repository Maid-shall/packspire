# 黒曜版画 全画面UI仕様

## 視覚基準

- 最上位基準: `docs/concepts/art-direction-candidates-2026-07/03-obsidian-misprint.png`
- 実装済み基準画面: ホーム
- 論理解像度: `1280x720`
- 1920x1080確認時: 論理座標の `1.5倍`

画面全体を生成画像で置き換えない。背景版、紙面、印章、装飾を独立素材として使い、人物、装備、敵、カード、盤面はゲームの既存データと共通部品を表示する。

## 共通座標

| 領域 | 論理座標 | 1920x1080表示 |
|---|---:|---:|
| 外周安全域 | `18-24px` | `27-36px` |
| 管理画面ヘッダー | `h:64-68px` | `h:96-102px` |
| 画面印章 | `52x52px` | `78x78px` |
| 一覧行 | `h:62-78px` | `h:93-117px` |
| 主要操作 | `h:48-54px` | `h:72-81px` |

選択状態で幅と高さを変えない。通常面から朱またはシアンの選択面へ画像だけを切り替える。

## 素材キット

- `Assets/Resources/Art/UI/ObsidianMisprint`: ホーム専用配達資料。
- `Assets/Resources/Art/UI/ObsidianMisprintShared`: 全画面共通の背景4点、面材12点、印章12点、装飾12点。
- 共有カード、占有形状、人物、装備、敵アートは既存正本を再利用する。

異なる旧素材を新しい面材の上へ重ねない。旧プレートが動的要素に残る場合はUSSで非表示にし、C#に新しい装飾生成を追加しない。

## 責務

- UXML: 固定背景、固定領域、画面印章、見当印、固定装飾、差込口。
- USS: 背景版、面材、座標、寸法、色、文字階層、状態差分。
- C#: データ一覧、カード、人物・装備・敵、イベント、意味クラス、遷移。
- カメラと`PanelSettings`は対象外。
