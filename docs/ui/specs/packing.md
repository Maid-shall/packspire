## 検証

実装前にUnity1920×1080、packing-context-before.png撮影成功。
既存PlayerPrefsの3保存キーはSessionStateへ退避して実プレイ確認。
Gate A→B→C→Dをシェル、一覧、選択文脈、動的操作の順に撮影・比較。
最終実画面: [確認用20個配置](../captures/packing-workspace-2026-10-03.png)。
実装前の保存キー3件を実プレイ終了後に完全復元し、値と存在状態の一致を確認済み。

- 標準6×4: セル76×76論理px。一覧4列、配置画像は装備ごとに1枚。
- 右の関連効果、下の全体LINK、色一致、所持品は独立スクロール。
  右を110.67までスクロールした時、他3領域の位置が変わらないことを確認。
- 所持0/1/4/12/20/100/500、検索0件、未配置フィルタ、空白解除を確認。
  空一覧のスクロール範囲が負にならず、位置0を保つことも確認。
- 仮の8×6・12×3盤でセル数、右欄の自動退避とオーバーレイ、横スクロール、
  拡大・回転後のドロップ座標を確認。寸法はQA用で、核マスタへ新盤は追加していない。
- ドラッグで占有形状・配置可否・LINK増減・一致差分を表示。
  プレビュー中にRunStateのシリアライズ結果が変わらないことを確認。
- 盤構成・装備由来札のポップアップを実画面で確認。
- PackingWorkspaceTests: 5件成功、失敗0。最後のコンソールError/Exception/Assertは0。
- 100個/500個の検索更新2回の同期生成時間は26.1ms/68.4ms（確認環境の参考値）。
  フレームレート保証ではない。500個は上限仕様ではなく負荷検証用。

## 保留・世界観差し替え

現行5核の寸法はすべて6×4。表示は核の寸法・属性・回転制限へ追従するが、
欠損マスや非矩形盤の新ルール、核ごとの固有素材、盤上の個別色編集は追加していない。
今回の正本は配置と操作の土台。世界観の方向は専用イラストを量産する前に決め、
背景・盤枠・セル素材・文字／色を交換する。世界観変更のために配置判定を作り直さない。
