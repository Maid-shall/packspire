複数ページを一枚の画像へまとめない。構図案の承認と部品素材の準備は別ゲートとする。

## ホーム由来のスタイルプロファイル

- 背景: 黒いマット面に低コントラストの街路版画。文字の背後はほぼ不透明な静かな面。
- 基本色: 炭黒、生成り、鈍い真鍮。朱は選択・主要決定、水色は接続・有効状態。
- 通常の線: 1論理px前後の細い罫線。繰り返しセルに角飾りや金属外枠を増やさない。
- 文字: 見出しは明朝系。タイトル26px以上、選択名22px、本文12px以上、補助10px以上。
- 装飾: 紙端・版ズレは選択や主要操作へ限定。低コントラストの余白を25%以上残す。
- アイコン: 既存の小型印・形状表示。盤固有の属性宝石は世界観として維持する。無関係な別キットの紫の矢印、過剰な全面発光、ゴシック多重枠は使わない。
- 画像: 人物・装備は境界のないオブジェクト絵。文字、動的数値は生成画像から切り出さない。
