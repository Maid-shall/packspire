# 共通UI・遠征導線の回帰確認

## 確認条件

- Unity Editor の Play Mode。1280×720論理座標、1920×1080実画面。
- 操作は UI Toolkit の PointerDown / PointerUp イベントで実行。
- PlayerPrefs の現行セーブ・staging・backupをEditor SessionStateへ退避し、終了後に元の値へ戻す。確認用の戦利品・遠征回数をユーザーの進行へ残さない。
- バランス測定ではない。通常操作の確認と、確認用状態による終端分岐の検証を区別する。

## 今回の実行結果

| 対象 | 方法 | 結果 |
|---|---|---|
| ホーム→荷造り→遠征準備→出発 | 通常ボタン操作、荷造り保存 | 実RunStateの通常遠征が開始。developer sessionはfalse |
| 戦闘→戦果→移動・次の選択 | 実戦のカード操作、勝利後3番目を選択、3秒待機して受領 | 選択と受領可能状態が維持され、次の区間へ復帰 |
| 敗北→拠点 | 実戦でHP0、終了境界の保存・再開、戻るボタン | 遠征内の敗北表示から直接ホーム。runと再開スナップショットを解放 |
| 第1層祠→続行 | 既存DevShowExpeditionCheckpointで到達状態を準備、通常の続行ボタン | 同じRunState、HP、戦利品を維持。次の候補は第2層 |
| 祠→帰還 | 確認用到達状態、通常の帰還ボタン | 終了理由Return。ホームへ戻り、再開スナップショットを解放 |
| 最深部クリア→拠点 | 第3層終了状態、通常の終了ボタン | 終了理由Clear。ホームへ戻り、再開スナップショットを解放 |
| イベント・休息・探索 | 生成ノードのLocation保存境界から再開し、実際の選択ボタンを操作 | Event/Otherは世界内、Restは全面イベント面。各ノードが一度解決され、awaitingResolution=false |

通常プレイ確認は勝利・戦果受領・次の区間・敗北帰還まで。
一回の通常遠征で最深部まで生存できることは今回の合格条件に含めない。
ボス後の分岐とクリアは状態準備を使った接続検証であり、難度の適正を証明しない。

## 発見して修正した接続・表示

- 通常遠征の終了後に旧GameClear/GameOver画面が重複していた。
  戦利品確定処理は維持し、遠征内の終了表示から直接ホームへ戻す。
  旧結果画面は旧導線用に残す。
- 休息イベントに旧幅440pxと旧アート寸法が残り、全面イベントが縦長に潰れ、ボタンが枠からはみ出していた。
  旧セレクタを除去し、画面固有USSの全面レイアウトへ統一。
  実測は論理座標x=92、y=76、w=1096、h=572。操作ボタン両端がパネル内に収まる。

## 残す課題

- 休息の建物外観は6地点別には描き分けていない。共通の休息用品イラストを使う。
- 祠の接近と実ボス戦からの接続は下記追補で確認済み。人間操作での一連の体感評価は後続。
- 遠征先の選択理由、勢力のシステム深化、役職のつまみ食い、家宝の成長表現は未決定のまま。新しいルールは追加しない。
- 敵の火力・遠征全体の消耗量と、通常プレイによる最深部到達の難度検証は後続。

## 追補: 休息・祠の専用素材

- 内蔵imagegenで共通休息用品と帰還祠の透過PNGを制作。
  [素材分類・ホーム由来スタイル・座標・生成プロンプト](specs/journey-interaction-art.md)を正本とする。
- 休息の左図像だけを差し替え、全面パネルの本文・ボタン配置は維持。
- 祠の巨大白印・青緑の仮フレームを除去。石と真鍮の物体を街路へ置き、
  本体と下の操作ラベルを一つの帰還Buttonにする。focus/hoverは操作ラベルへ限定。
  続行ボタンも地面近くへ移す。C#のゲームルール・効果値は変更しない。
- Unityの既定NPOTリサイズが縦横比を変えるため、両PNGはNPOT Noneで取り込む。
  元画像寸法・透過・mipmapなしと、祠アートが帰還Buttonの子であることを回帰テストに追加。
- 全EditModeテスト175件成功、失敗0、skip0。
- 通常UI入力で休息を解決しHP31→34、未解決フラグ解除を確認。
  第1層祠から続行すると同じRunState・HP・戦利品のまま第2層候補2件。
  第2層祠の画像中央をクリックするとHubへ帰還し、runと再開スナップショットを解放。
- 実画面: `Temp/interaction-art-rest.png`、`interaction-art-shrine.png`、
  `interaction-art-shrine-idle.png`、`interaction-art-shrine-second.png`、
  `interaction-art-rest-1.png`、`interaction-art-rest-2.png`。
  休息6文面すべてで題名の一致、本文とボタンのパネル内収容、第二選択肢の無効化を確認。
  水没書庫・黒鐘区画の長めの本文も実画面で折返し・コントラストを比較済み。
- Play Mode中にテストコードを追加した際、再コンパイルで環境演出の非シリアライズ配列が失われ、
  IndexOutOfRangeが出た。確認セッションを停止して再起動し、ホットリロード後の状態をQA判定に使わない。
  この追補では環境演出コードの変更は行っていない。

## 追補: 戦果受領から祠前へ歩く接続

- 解決済み第1層ボスのReward保存状態を準備し、3番目の候補選択・受領から
  実際のUI入力で接近、停止、続行、帰還を確認。ボス戦自体を通常プレイした結果ではない。
- 祠は戦果受領直後から見え、到着前は帰還・続行操作を隠して無効化。
  地面のWorldAdvancedと同じ距離で移動し、祠前で減速・停止後に選択肢を表示。
- 通常速度と倍速で到着を確認。祠の論理座標移動量と地面実移動量の投影差は
  それぞれ0.00005px未満。一時停止・台帳中は両方停止し、接近中のジャンプも可能。
- 続行では祠本体を残したまま後ろへ流し、同じRunState・HP・経過日数を維持して第2層候補へ。
  祠本体クリックで帰還すると終了理由Return、Mainへ戻り、runと再開スナップショットを解放。
- 接近中に再開するとCheckpointから到着状態を復元。受領済みの消耗品数・HP・日数を維持し、
  二重付与なし。UnityのJSON復元で空のrewardOfferオブジェクトが生成される場合も、候補は空で
  保存stageはCheckpoint。nullだけを前提にした確認判定は使用しない。
- 通常戦闘後は祠を出さず既存の離脱歩行からChoiceへ。最深部ボス後も祠を出さずResultへ。
  これらは生成ノードの解決済みReward状態を使った分岐回帰確認。
- 全EditModeテスト179件成功、失敗0、skip0。新規確認セッションのConsole Error/Exceptionは0件。
- 実画面: `Temp/shrine-approach-start.png`、`shrine-approach-middle.png`、
  `shrine-approach-arrived.png`、`shrine-approach-depart.png`、
  `shrine-approach-x2-start.png`、`shrine-approach-x2-arrived.png`、

## 追補: 本番ボス戦を含めた祠への接続

- 現行ロードアウトのHP42、8日目、生成航路のボス直前ノード解決状態だけを準備。
  Choice再開から既存の一択自動進行、接近、戦闘突入を通す。未解決ボスのHPは36。
  戦闘確認所の撃破代行や敵HPの書換えは使わず、UIカード操作（攻撃優先）で撃破した。
  第1層開始からの連戦や、人間による予兆認識率の測定ではない。
- 通し確認で封鐘の番人の戦果がDangerになっていた。遭遇はボス専用だが数値variantはCommonで、
  報酬処理がvariantとriskだけを見ていたため。Bossノードを報酬分類へ渡し、既定のBoss保証を適用。
  敵HP、威力、タイムライン、数値variant、報酬抽選率自体は変えていない。
  通常／危険／精鋭／ボスの既存分類を保つ回帰テストも追加。
- 時間ダメージによる撃破だけが敵消失・区間突破演出を迂回して戦果を即時表示していた。
  既存のJourneyBattleVictoryPresentationRoutineへ接続し、直接攻撃と同じ撃破・霧の順にする。
- 修正後は実カード戦闘で36→0、撃破・区間突破状態を経てBoss戦果へ。
  約39.5秒、カード10回、戦闘後HP29（戦闘終了時26＋既存勝利回復3）。
  反応キーの機会はこの一戦では0で、反応入力の検証結果とは扱わない。
- 3番目の装備候補を選んで3秒待っても選択・受領可能状態を維持。
  装備は一度だけ戦利品バッグへ。歩行・祠到着・続行でもHP29、8日目、戦闘勝利1回を維持。
  祠の移動量と地面移動の投影差は0.00001論理px未満。
  到着時に戦闘開始／終了クラスと手札・リール表示が残らないことを確認。
- 続行は同じRunStateの第2層候補へ。実撃破後のCheckpoint保存状態を復元し、
  祠本体クリックでReturn帰還した場合も、選んだ装備のUIDが拠点stashへ保持される。
  runと再開スナップショットを解放し、旧結果画面を挟まずMainへ戻る。
- 別の実戦も約33.4秒、カード8回で撃破（戦闘後HP37）。撃破バナーは
  実際のROUTE CLEARED文字とopacity=1の表示完了状態で撮影・比較。
  この実戦からも戦果受領→祠→直接帰還を確認し、選んだ装備を保持。
