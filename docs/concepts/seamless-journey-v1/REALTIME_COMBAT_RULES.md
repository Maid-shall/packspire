# リアルタイム戦闘 共通時間ルール

更新: 2026-08-25
状態: 共通ルール採用、数値は仮調整値

## 目的

カードを任意時点で使えるだけの戦闘ではなく、同じカードでも使用時刻によって価値が
変わる戦闘にする。敵の10秒予告リールを判断の正本とし、共通ルールが予告時刻を
無断で移動させないようにする。

## 採用した共通ルール

### 開幕の確認時間

- 初回敵行動の実行基準は戦闘時計の10.001秒以降とし、通常の10秒リールへ早い段階から行動票を入れる。
- エナジー補給と手札補充は戦闘時計12.8秒まで発生させない。
- 初回補給は敵行動票の入場時刻に依存せず、通常の6.4秒周期の2回目にあたる12.8秒へ固定する。以後は6.4秒周期で補給する。
- 戦闘開始演出が完了するまでは戦闘時計と入力を止め、BATTLE START表示の終了と同時に入力を解放する。
- 入力解放後はカードを即座に使用できる。ブロック減少と状態効果は通常の戦闘時計で進む。
- 0.001秒の端数は表示境界に行動票が見えることを防ぐ実装上の余白である。

### ブロックの時間減少

- プレイヤーと敵のブロックへ同じ時間減少規則を適用する。
- ブロック獲得直後は仮に1.0秒間、全量を維持する。
- 維持時間後は仮に毎秒3ブロックずつ減少する。
- 追加獲得時は維持時間を更新する。
- 被弾時は従来どおりブロックから先に消費する。
- 敵ブロックを超えた攻撃ダメージは敵HPへ通す。
- ポーズ、入力ロック、山札・捨札表示中は減少を止める。
- カードホバーによる戦闘スロー中は、敵行動と同じ比率で減少を遅くする。

敵の防御は、プレイヤーへ待機だけを強制する完全無敵ではない。攻撃して早く削るか、
カードとエナジーを温存して自然減少を待つかを選ぶ。敵が完全防御してもプレイヤーへ
共通の硬直・弱体・敵反撃を付与せず、ブロック破壊にも共通報酬を付けない。

### プレイヤーの完全防御と反撃機会

- 一連の敵攻撃が終わるまでにHPダメージを一度も受けなかった時だけ完全防御とする。
- 連撃は一発単位ではなく、行動列全体で判定する。
- ジャンプ成功はHPダメージ0なので完全防御になり得る。
- 踏ん張り成功は半減だけでは完全防御にならない。既存ブロックを含めて最終的に
  HPダメージ0なら完全防御とする。
- 完全防御後、仮に1.6秒間の反撃機会を得る。
- 反撃機会中の次の攻撃カードだけ、仮に基礎ダメージ+25%（端数切上げ）する。
- 反撃機会は重複せず、攻撃カード使用または時間切れで消える。
- 反撃は敵行動時刻を変更しない。

敵は事前生成された行動列で動くため、敵の完全防御へ同じ反撃機会を与えない。
敵が防御を利用してプレイヤーを罰する挙動は、表示可能な敵固有能力としてのみ追加する。

### 強化・弱体の秒数管理

- 即時、時間制、次回消費、戦闘中永続を効果の基本分類とする。
- 旧ターン制データを壊さず、リアルタイム戦闘ではduration 1を補給周期と同じ
  6.4秒へ変換する。
- 弱体、脆弱、強化、防具破壊などは残り秒数が0になると解除する。
- 火傷、毒、再生は戦闘時計の6.4秒ごとに解決する。
- 毒は周期ごとに蓄積を1減らす。火傷と再生は設定時間が終わるまで蓄積値を維持する。
- 状態チップへ残り秒数を表示し、リアルタイム戦闘のカード本文はターン表記を秒へ
  読み替える。

## 専用カード・敵固有能力へ予約する効果

次は共通ルールへ入れず、カード、装備、役職、消耗品、敵固有能力として明示する。

### 敵行動列への干渉

- 遅延: 確定前の敵行動を指定秒数だけ後ろへ動かす。
- 全体遅延: 確定前の複数行動を小さく後ろへ動かす。
- 中断: 条件を満たした時だけ、現在の未解決予兆を取り消す。
- 鈍化: 一定時間、今後生成する敵行動パターン全体を遅くする。

行動時刻を変えた場合は、リール上の票を移動させ、変更後の時刻を即時に正本表示する。
通常攻撃、完全防御、通常の反撃では行動列を動かさない。

### 敵ブロックへの干渉

- 破砕: 敵ブロックへ追加ダメージを与える。
- 貫通: 敵ブロックの一部を無視する。
- 突破: 敵ブロックを超えたダメージを増幅する。
- 崩し: そのカード自身が十分な量のブロックを削った時だけ追加効果を得る。

崩しは、時間減少後に残った1～2ブロックを小攻撃で割って利益だけを得られない条件にする。
必要なら「元のブロック量に対する、そのカード自身の削減割合」を判定に使う。

### 防御反撃と接触罰

- 敵防御中への攻撃で反撃する。
- 反射ダメージや棘ダメージを返す。
- 完全防御後の次行動だけ強化する。
- 特定攻撃カードを弾いて短い硬直を与える。

これらは敵が自律判断して隙を利用する共通AIとして扱わず、敵行動票・状態アイコン・
説明文へ事前表示できる固有能力として扱う。

### プレイヤー側の上位反撃

- 完全防御後にエナジーを返す。
- 完全防御後にドローする。
- 反撃機会を複数回消費できるようにする。
- 指定種類の攻撃だけ反撃倍率を上げる。

基本の+25%を置き換えるか追加するかはカードごとに明示し、無条件重複はさせない。

## 調整時に測る値

- 防御カード使用から被弾までの平均秒数。
- 獲得ブロックのうち、被弾吸収・時間消滅・戦闘終了残存へ分かれた割合。
- 完全防御率と反撃機会の使用率。
- 敵ブロックに対して攻撃した回数と、待った秒数。
- 状態効果が実際に有効だった秒数と発動回数。
- 通常敵、精鋭、ボスで防御行動が占める時間と頻度。

数値は単戦の印象だけで変更せず、戦闘確認所と代表経路の総消耗で比較する。
