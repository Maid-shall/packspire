# PACKSPIRE UI information architecture v2

更新: 2026-08-27
用途: 画像モックを実装へ移す際の情報基準。画像内の生成文言や数値より本書を優先する。

## 共通原則

- 画面ごとに、プレイヤーがその場で行う判断を一つに絞る。
- 同じ操作を中央パネルと下欄など二か所へ重複させない。
- 遠征中の持続情報と、現在の状態だけで必要な情報を分離する。
- 日数は常設の経過記録ではなく、危険段階と経路比較へ使う。
- 旧互換の回収郵便数を常設HUDへ出さない。
- 配達印は使用できる分岐・台帳で見せ、通常移動中は常設しない。
- 情報が少ない状態では装飾で空欄を埋めず、欄そのものを縮めるか隠す。

## 遠征準備

主判断: 行先、配達人、荷造りを確認して出発する。

- 行先一覧: 行先名、全3層、開始危険段階、解放状態。
- 行先概要: 目的、遭遇傾向、成果傾向、特殊規則。
- 配達人: HP、役割に直結する固有能力、変更導線。
- 荷造り: 装備数、生成カード構成、バックパック容量、変更導線。
- 下部: 行先、配達人、荷造りの最終確認と「遠征を開始」だけ。

出さない: 出発予定日、天候、郵便回収数、意味のない100%倍率、重複する出発操作。

## 遠征中の持続欄

- 現在HP。
- 現在階層とボスまでの進行。
- 現在の危険段階と次段階までの日数。
- 保護済み新規戦利品。
- 未収納新規戦利品と敗北時喪失の警告。

人物肖像、役職説明、天候、経過日の大見出し、回収郵便数、印総数は常設しない。

## 状態別の下欄

| 状態 | 表示 |
|---|---|
| 移動 | 次の判断、区間進捗、速度、一時停止 |
| 分岐 | 非表示。経路カード自体を操作する |
| イベント・休息・探索 | 非表示。中央の判断だけを操作する |
| 戦闘 | 旅HUDを退場させ、戦闘HUDへ交代する |
| 戦果 | 非表示。戦果ポップアップだけを操作する |
| 階層終了 | 非表示。帰還／続行パネルだけを操作する |
| 遠征終了 | 非表示。専用結果画面へ移る |

## 経路選択

二つの候補で、同じ順序の比較軸を使う。

1. 区間日数。
2. 選択後の危険段階。
3. 遭遇傾向。
4. 成果傾向。

カードを選ぶ操作を確定操作とし、画面下へ別の決定ボタンを置かない。

## 階層終了

主判断: 現在の成果を確定して帰還するか、危険に晒したまま次階層へ進むか。

- 帰還側: 確定する全戦利品。
- 続行側: 現在HP、未収納戦利品、敗北時損失、次階層開始時の危険段階。
- 経過日数、戦闘回数、地点数は判断へ不要なら省く。
- 帰還と続行の操作は中央パネル内に一度だけ置く。

## 遠征終了

- 敗北: 持ち帰る物と失う物を最優先する。
- 途中帰還: 確定した成果を最優先する。
- 完全踏破: 全戦利品の確定と第3層到達を最優先する。
- 三種類を同じ外観・同じ見出しで済ませない。

## 拠点ページの主役

| ページ | 主役 |
|---|---|
| 配達人 | 選択した人物によるプレイ差 |
| 荷造り | 6x4配置盤と、そこから生じるカード・能力・LINK |
| 保管庫 | 所持品の検索、比較、管理 |
| 図鑑 | 発見状況と既知情報の参照 |
| 商店 | 在庫選択、効果確認、購入結果 |
| 役職記録 | 役職効果、成長枝、任命 |
| 家宝 | 現在効果、成長先、継承 |
| 勢力 | 階級、貢献度、勢力効果、他勢力との関係 |

## モックの扱い

- `01`から`17`は一画面一枚の構図案。
- 画像内の生成された固有名、効果値、アイテム名は実装値ではない。
- 戦果選択と帰還結果は前案の採用方向を再収録した。
- 実装前に現行データへ接続できる項目だけをPresenterへ渡す。
