# 遠征・拠点UI方向確認 2026-08-27

画像モック確認後の方向整理。ゲームルールへ影響する項目は、採用確認前に実装しない。

## 確定方向

- 経路選択は現行の二枚の経路票を維持し、位置ずれ、基準線、余白、文量差、選択状態を商品レベルへ直す。情報構造の全面置換はしない。
- イベントは規模で二段階に分ける。荷物を開けるか無視するかなど、その場で完結する小判断は遠征世界内へ選択肢を出す。商人、施設、人物とのまとまったやり取りは、対象が世界内へ現れ、接近・インタラクトした後に遠征画面全体へイベント面を重ねる。
- 全画面イベント面は左にイラスト、右に本文と選択肢を置く。ボタンは本文を圧迫する大きさにせず、通常HUDは判断中だけ隠す。
- キャラクター選択は、一覧・人物画・実用情報・決定の現方向を維持する。
- 荷造り全体の再設計は保留する。左の所持品欄だけは、保管庫・図鑑で採用するセル、フィルター、選択状態へ合わせる。
- 保管庫は一覧面積を増やし、詳細欄を縮める。占有形状はマス目、向き、占有セルが一目で分かる専用表示を維持する。
- 図鑑は一覧・発見状況・記録詳細の現方向を維持する。
- 商店は現行構図をブラッシュアップし、商人の存在と売買の相手が見える状態を残す。
- 遠征中の移動操作としてジャンプとクリック／インタラクトを追加する。ジャンプは回避予兆などの特定状況に限定せず、通常移動中も常に行える基礎操作とする。インタラクトは人物、施設、帰還物など対象がある時だけ案内する。
- 遠征中の常設UIはHP、遠征印、小さなバッグ入口を基本とする。後続の承認により、日数は左共通欄の時計で常設する。歩行に合わせて時計が満ち、日付が進む。危険段階は変化時の通知と台帳で確認させる。

## 有力候補・次の確認対象

### 遠征中の常設UI（方向確定・実画面調整待ち）

- 左欄はHPと遠征印を中心にする。
- 遠征印は縦リール状に吊り、通常移動中は確認可能、使用できる状態では選択可能にする。
- 回収品・保護済み／未収納戦利品は常設一覧にせず、小さなバッグボタンから確認する。
- 左欄へ人物肖像、役職説明、回収郵便数、天候を常設しない。日付の時計だけは後続の承認に基づいてHPと遠征印の間へ置く。
- HPへ影響する持続状態が将来追加された場合だけ、HP直下へ小さな状態アイコンを追加する。未実装情報のための空欄は作らない。

### 遠征中の下欄

- 現行の全幅下欄を当然の前提にしない。
- 自動移動中に「次の判断まで」を予測できることだけが必要なら、細い一時進捗または短い表示へ縮小する。
- 始点・終点名、常設の区間説明、重複する状態文は出さない。
- 速度と一時停止は小さな操作群として画面端へ分離できる。
- 分岐、イベント、戦果、階層終了では下欄を隠す。

### 階層ボス後

- ボス撃破後すぐに中央メニューを出さず、短い歩行区間の先へ祠、帰還門、転送装置などの帰還物を置く案を優先する。
- 帰還は帰還物へのクリック／インタラクト、続行は先へ歩く操作として、旅の中で選ばせる。
- 誤操作を避けるため、不可逆な確定の直前だけ短いホールドまたは確認を検討する。

### 遠征終了

- 成功・失敗とも専用の大きな集計画面を必須にしない。
- 遠征画面を残した軽い終了表示を基本候補とする。
- 敗北時だけは、保護して持ち帰る物と失う物を最小限の一行または展開可能な詳細で確認できるようにする。
- 敗北は戦闘開始演出と同じく背景・敵・プレイヤー位置を保ち、プレイヤーの落胆ポーズと短い「遠征失敗」表示を重ねる。別の結果背景へ切り替えない。
- 通常遠征の終了表示からは戦利品を確定して直接拠点へ戻る。旧式の大きな結果画面を二重に挟まない。旧導線用の結果画面自体は互換性のため残す。

## 未決定

### 遠征先選択

- 行先ごとの選択理由そのものを再設計してから画面を決める。
- 背景絵、敵倍率、報酬倍率を並べるだけの画面にはしない。
- ダンジョンごとに何を選び分けるのかが決まるまで、新モックを実装基準にしない。

### 勢力

- 現行の階級、貢献度、効果一覧だけで十分かを含め、システム側から掘り直す。
- UIの表面調整だけで確定しない。

### 家宝

- 複数家宝を収集・選択する画面にはしない。
- 一つの家宝をどう成長・継承・変化させるかを主役にする。
- 現行の情報羅列に代わる操作と成長表現を決めてから再設計する。

### 役職

- 現行は基本役職4つ、各役職の二択分岐、任意の資格印1つを持つ。
- 基本役職を軸にしつつ、別系統の能力を少数だけ取得・装着する「つまみ食い」方式を再検討する。
- 戦闘、経路、イベント、遠征印、ジャンプ／インタラクトの能力を同じ枠へ無制限に混ぜず、取得枠とカテゴリ制限を先に決める。
