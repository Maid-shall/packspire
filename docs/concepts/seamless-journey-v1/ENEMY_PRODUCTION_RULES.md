# 遠征敵キャラクター量産ルール

更新: 2026-08-25  
状態: 2地域パイロット実装済みの正本  
対象: 通常100、強化50、精鋭30、ボス20の量産方針

## 1. 目的

敵を200体へ増やしても地域の個性を失わず、同時に全員を完全新規制作するコストを避ける。
再登場系統は量産手段の一つに限定し、地域固有敵を置き換える手段にはしない。

## 2. 敵の出自区分

各敵は強度とは別に、次の出自を一つ持つ。

| 出自 | 内容 |
|---|---|
| 地域固有 | その地域で初めて成立する外見・行動・背景設定を持つ |
| 再登場系統 | 前地域の敵と判別可能な共通骨格を持ち、地域装備と一部行動を変更する |
| 特殊再登場 | 以前の精鋭・ボスを、後半の強敵や別役割として意図的に再構成する例外枠 |

通常、強化、精鋭、ボスの強度分類と、この出自区分を混ぜない。
たとえば「精鋭」には地域固有精鋭と再登場精鋭の両方が存在する。

## 3. 必須ルール

1. 各地域は地域固有の通常敵を持つ。
2. 各地域は少なくとも一系統の地域固有精鋭を持つ。再登場精鋭だけで地域を構成しない。
3. 再登場系統は通常敵の一部と精鋭の一部だけに使う。全敵へ適用しない。
4. 初登場ボスは原則として一回限りとする。後半の色違い・残響個体は特殊再登場枠であり、新地域の固有ボス数には数えない。
5. 色替えだけを別個体として数えない。装備、材質、輪郭、地域記号、行動差分のうち複数を変える。
6. 再登場個体は、初見でも同系統だと分かる共通輪郭・武器・予兆・行動文法を残す。
7. 地域差分で変更する行動は原則1～2個に留め、既知の敵を再学習する楽しさを壊さない。
8. 地域固有精鋭は、その地域の環境かルート判断を一つ以上戦闘へ持ち込む。

## 4. データ分離

敵の量産は次の部品を合成する。

```text
EnemyLineageDefinition
  共通輪郭 / 共通装備種 / 基本予兆 / 基本行動文法

JourneyEnemyDefinition
  個体ID / 表示名 / アート / 基礎HP / 地域 / 出自

RealtimeEnemyBehaviorCatalog
  全敵で共有するA / C / G / J / Bの順序と時刻だけの汎用タイミング候補

RealtimeEnemyTimelineProfile
  敵固有コマンド / 汎用タイミング5～6個 / 全体速度倍率 / 開幕 / fallback / HPフェーズ

JourneyEnemyVariantDefinition
  通常 / 強化 / 精鋭 / ボス分類と数値補正

RegionalEnemyOverride
  地域装備 / 材質 / 属性 / 差し替え行動1～2個 / 出現条件

JourneyBattleEncounterProfile
  上記部品と階層・日数・ルート・抽選条件の束ね
```

現在ある`JourneyEnemyDefinition`、`RealtimeEnemyTimelineProfile`、
`JourneyEnemyVariantDefinition`、`JourneyBattleEncounterProfile`を維持する。
パイロットでは`JourneyEnemyLineageDefinition`を追加し、地域火力差は
共有タイミング型を複製せず`regionalDamageMultiplier`と敵固有コマンドで与える。
タイミング本体は`RealtimeEnemyBehaviorCatalog`へ分離し、200体×5～6個を
すべて個別制作しない。基本速度差は`timingScale`で型全体へ一度だけ適用する。

## 5. 一体を正本化する戦闘演出契約

完全制作する敵は、行動ルールとは別に`JourneyEnemyBattlePresentationProfile`を持つ。  
このプロファイルはゲームの威力、実行時刻、受付時間を変更せず、行動イベントを次の絵と座標へ対応させる。

| 項目 | 正本仕様 |
|---|---|
| 6ポーズ | `Idle` / `HighAnticipation` / `HighImpact` / `LowAnticipation` / `LowImpact` / `Hit` |
| 発光点 | High / Lowの各予備動作絵に、画像矩形左下を`(0,0)`、右上を`(1,1)`とする武器先端座標を一つずつ持つ |
| 接地点 | High / Lowの各命中絵に、同じ正規化座標で接地火花の位置を一つずつ持つ |
| 発光表現 | 反応受付開始時に一度だけ、行動色の十字光、白芯、細いリング、局所的な暗色下地を同一点へ出す |
| 命中表現 | 命中絵へ切り替え、接地点に予兆より小さい一回火花を出す。防御行動にはタイミング光も接地火花も出さない |
| 復帰 | 命中保持後0.24秒は命中絵を完全不透明のまま位置・角度・縮尺だけ減衰復帰させ、終端近くで次の絵へ一度だけ切り替える。接地火花は0.38秒で減衰し、全身の暗転、クロスフェード、二重表示は使わない。連撃途中はHigh / Lowの予備動作へ、列の終端は`Idle`へ戻る |

封鐘の番人を最初の正本とする。6枚は同寸、同足元pivotで、上段は掲げた鐘、下段は右へ引いた武器、各命中は地面の接触箇所へ座標を置く。  
`motionLane`がHigh / Lowを選び、行動種別が発光色とジャンプ／踏ん張り判定を選ぶ。タイミング表と個別コマンドは演出プロファイルを参照しない。

## 6. 最初の小規模試作

灰市外縁と水没書庫の2地域で、次だけを作って比較する。

| 枠 | 灰市外縁 | 水没書庫 | 検証目的 |
|---|---|---|---|
| 再登場通常1系統 | 灰塵装備 | 防水・腐食装備 | 同じ敵だと分かりつつ地域差が出るか |
| 地域固有通常 | 1体 | 1体 | 再登場系統が地域性を薄めないか |
| 地域固有精鋭 | 1体 | 1体 | 地域の象徴として成立するか |
| 再登場精鋭 | 保留 | 保留 | 通常敵試作後に必要性を判断する |
| ボス | 作らない | 作らない | この試作では例外再利用を評価しない |

再登場比率はこの段階では固定しない。実画面、10秒行動列、複数遭遇の反復感を確認してから決める。

### 実装したパイロット

| 地域 | 再登場系統 | 地域固有通常 | 地域固有精鋭 |
|---|---|---|---|
| 灰市外縁 | 灰鐘の巡視兵 | 煤管さらい | 炉灰の執行官 |
| 水没書庫 | 水封じの巡視兵 | 濡れ索引人形 | 封庫の鍵守 |

- 最初の共有カタログは技名・威力を持たない40種類の汎用タイミングで構成する。
- 全パイロットは共有カタログから6タイミングを装備し、敵側に5種類のコマンドを持つ。
- 鐘番系統は6個中5個を共有し、灰市外縁／水没書庫で汎用タイミング1個を差し替える。
  見た目と技内容の地域差は敵固有コマンド側で与える。
- 地域固有通常と精鋭も汎用タイミングを使い、固有コマンドとHP後半の重みで差を作る。
- 番人ボスは共有タイミングを残し、圧力・反応要求の比率をHPフェーズで変更する。
  専用タイミングは実戦で必要性が確認できた場合だけ追加する。
- 通常抽選重みは地域固有通常4、再登場通常2、地域固有精鋭1の初期値とする。
- 旧番人遭遇はボス専用へ移し、通常戦の全地点共有を終了した。
- `JourneyEnemyProductionAuditSystem`が、両地域の固有通常・固有精鋭と
  再登場系統の地域横断を静的検査する。

## 7. 合格条件

- 名前を隠しても、再登場2体が同系統だと分かる。
- 色をモノクロ化しても、地域固有敵と再登場敵を輪郭で区別できる。
- 地域固有精鋭が、再登場通常敵より地域の主役に見える。
- 再登場個体の既知予兆を流用でき、追加予兆だけを学べば戦える。
- 地域差分を作るために本体コードを変更しない。
- 一地域を追加するとき、既存敵の複製・直書き・分岐追加を必要としない。

## 8. 量産へ進む条件

試作2地域をUnity実画面で比較し、外見、行動列、遭遇頻度の三点が合格してから、
通常・精鋭それぞれの再登場比率と一地域あたりの最低固有数を決める。
数値目標100/50/30/20は維持するが、内訳を先に埋めるための水増しには使わない。
