# シームレス遠征 背景素材共通仕様

役割: 背景制作時の美術・構図契約。Unityへの登録、命名、Catalog設定は
[`JOURNEY_BACKGROUND_ASSET_SPEC.md`](JOURNEY_BACKGROUND_ASSET_SPEC.md)を正本とする。

更新: 2026-08-14  
対象: `JourneyAnimationPrototype` の通常移動画面  
状態: 灰市外縁の本番背景を作る前の制作契約

## 1. 目的

背景、地面、小物を別々に制作しても、同じ街路・同じ光・同じ接地面に見えるようにする。
本仕様を満たさない素材は試作確認には使えても、本番用背景セットには採用しない。

## 2. 基準キャンバスと実表示領域

### UI基準

- UI Toolkit論理座標: `1280 x 720`
- QAキャプチャ: `1920 x 1080`
- UI表示倍率: `1.5`
- 左レール: 論理 `x=0..190`
- 上HUD: 論理 `y=0..64`
- 下HUD: 論理 `y=628..720`
- 通常移動で見える舞台: 論理 `x=190..1280`, `y=64..628`
- 1920キャプチャ上の舞台: `x=285..1920`, `y=96..942`

背景は全画面の裏へ敷くが、構図の主役、ランドマーク、重要な接続部は上記の舞台内へ置く。
左レールの裏へ重要物を置かない。

### ワールド基準

- Orthographic Camera Size: `5.0625`
- 16:9時のカメラ範囲: 幅 `18.0`、高さ `10.125` world units
- カメラ中心: `(0, 0)`
- 全画面範囲: `x=-9.0..9.0`, `y=-5.0625..5.0625`
- UIを除いた通常舞台の目安: `x=-6.328..9.0`, `y=-3.769..4.163`
- 配達人の通常表示X: `-3.6`
- 配達人の接地Y: `-2.95`

## 3. 不変ガイド

### 接地線

すべての道路チャンクは `world y=-2.95` を歩行接地線として通す。

- 広場、標準街路、橋、回廊で接地線を変えない。
- 道幅は、接地線より奥側へ見える床面量と手前側の縁の厚みで表現する。
- 坂道や階段は通常移動用チャンクに入れない。イベント用の特殊構図として別管理する。
- 小物の接地点と影の中心も同じ道路面へ合わせる。

### 地平・都市基準

- 基準地平線: `world y=0.75`、画像上端から約 `460px`
- 最遠景の塔は地平線から立ち上げる。
- 中景の建物基部は道路面より奥へ置き、地面の上へ貼り付けない。
- 全チャンクで消失点、建物の垂直線、路面の視点高を変えない。

### 安全領域

- キャラ可読領域: `world x=-5.2..-1.6`, `y=-3.15..1.35`
- この範囲では、キャラ輪郭と同程度の明るい窓・細密な看板・巨大な縦線を避ける。
- 主ランドマーク領域: `world x=2.0..7.4`, `y=-2.95..3.8`
- 画面中央上部はトースト表示に使うため、重要な文字や顔を置かない。

## 4. 素材の書き出し契約

### 共通

- 1チャンク: `1920 x 1080 PNG`
- Pixels Per Unit: `100`
- フィルター: Bilinear
- sRGB: On
- Mip Map: Off
- Wrap: Clamp。ループは画像のWrapではなくチャンク配置で行う。
- フルスクリーンレイヤーのPivot: `(0.5, 0.5)`
- 左右端は同じ高さ・同じ道路断面で接続できること。
- 透明素材へ市松模様、黒背景、白フリンジを焼き込まない。
- 完成画像を後から切り分けず、最初からレイヤー別に制作する。

### 不透明と透明

- `Sky`だけは完全不透明RGB。
- `Cloud / Far / Mid / StreetBack / Ground / Prop / Occluder / Weather`はRGBA透過。
- 透明画素のRGBへ黒を残さず、半透明縁は本体色で塗り足す。
- 透明レイヤー単体を黒背景で確認した後、最終合成でも輪郭を確認する。

### 個別小物

- 小物は等幅スプライトシートへ詰めない。
- 原則として1物体1PNG、またはSprite Editorで手動矩形を定義したAtlasを使用する。
- Pivotは物体の実接地点。荷車は両車輪の中点、街灯は台座中央、石材は最下面中央。
- 物体の影を本体へ焼き込む場合は道路面方向と一致させる。
- 接地影を動的に付ける物体は、影を本体画像へ二重に描かない。

## 5. レイヤー構成

| 層 | 内容 | Sorting Order目安 | 基準速度 | 時間帯処理 |
|---|---|---:|---:|---|
| Sky | 空の色、遠い光 | -70 | 0.00 | Day/Dusk/Nightをクロスフェード |
| Cloud | 雲、煤煙 | -60 | 0.025 | 色と不透明度 |
| Far | 都市シルエット | -50 | 0.08 | 全体Tint、霧量 |
| Mid | 塔、橋、建築群 | -40 | 0.22 | 全体Tint |
| StreetBack | 柵、壁、路肩 | -20 | 0.55 | 全体Tint |
| Atmosphere | 霧、光芒、雨幕 | -15～35 | 状態別 | 不透明度 |
| Ground | 歩行面、縁、下部構造 | -10 | 1.00 | 全体Tint、濡れ差分 |
| RearProp | 柵の後ろの看板、荷物 | 4～8 | 0.75～0.90 | レーンTint |
| Courier | 配達人と接地影 | 10 | 固定 | キャラ可読補正 |
| Actor | 敵、NPC、拾得物 | 18～24 | 状態別 | 個別 |
| FrontProp | 路面手前の小物 | 26～32 | 1.05 | レーンTint |
| Occluder | 手前を横切る柱、布、配管 | 40 | 1.25～1.40 | 暗めに固定 |

Sorting Orderは暫定値だが、役割の前後関係は固定する。複数スプライトで構成するランドマークは
`SortingGroup`で一単位にする。

## 6. 道路プロファイル

灰市外縁では最低3種類を用意する。キャラ位置と接地線は変えない。

### Wide / 門前・広場

- 奥行きのある床面を広く見せる。
- 荷車、検札所、複数NPCを置ける。
- 柵や建物は画面奥へ下げる。
- 重要判断やランドマーク前に使う。

### Standard / 通常街路

- 現在より床面を少し広くし、日常の移動に使う。
- 路肩小物を置けるが、連続する街灯列にはしない。
- 背景チャンク列の基準接続形。

### Narrow / 橋・保守通路

- 現在の細い高架に近いが、特殊区間として短く使う。
- 大型小物を置かない。
- 強風、障害物、荷崩れなどの予告に使える。

道路プロファイルはランダムに毎画面変更せず、10～20秒相当のチャンクとして構成する。

## 7. 小物配置レーン

| レーン | 接地Y目安 | Scale | 速度 | 用途 |
|---|---:|---:|---:|---|
| Rear | -2.40～-2.62 | 0.72～0.88 | 0.75～0.88 | 柵の後ろ、遠い荷物 |
| Roadside | -2.78～-2.95 | 0.88～1.02 | 0.92～1.00 | 看板、街灯、荷車 |
| Front | -3.12～-3.42 | 1.04～1.20 | 1.05～1.16 | 手前の石材、配管 |
| Occluder | 個別 | 1.15～1.45 | 1.25～1.40 | 一時的な画面遮蔽 |

- Scaleをランダム化したら、必ず対応レーンのY・速度・Sorting Orderも変える。
- 街灯と大型門はランダム小物にせず、チャンクまたはランドマークへ所属させる。
- 同一小物の再出現には最低2チャンク分の間隔を置く。
- 小物密度は区画定義で管理し、常に1個出ている状態にしない。

## 8. 光・色・時間帯

### 制作時の中立状態

- 基準時間: 煤霧の薄い昼
- 主光源: 画面左上からの弱い冷色光
- 窓、ランタン: 局所的な暖色
- 地面、建物、小物で同じ光方向を守る。
- 遠景ほど低コントラスト・低彩度・明るい霧色へ寄せる。

### ランタイム変化

URP/2D Lightを前提にせず、現在のSpriteRenderer構成で実装する。

- 空: `Day -> Dusk -> Night` の3枚をクロスフェード。
- 雲・煤煙: 透明レイヤーのTintとAlpha。
- 建築: レイヤーごとのTint。遠景ほど変化を強くする。
- 窓明かり: 建築と分離した発光風オーバーレイのAlpha。
- 霧・雨: 専用透明レイヤー。
- 進行値は区間内時間ではなく遠征全体時間を使う。

## 9. チャンク接続規則

- 各チャンクは `EntryTag` と `ExitTag` を持つ。
- 初期タグは `Wide / Standard / Narrow / Landmark`。
- `ExitTag`と次チャンクの`EntryTag`が一致するものだけ接続する。
- 接続端から左右`128px`には、途中で切れる大型建築やランドマークを置かない。
- Groundの左右端は同じ接地線、同じ床厚、同じ明度へ合わせる。
- MidとStreetBackは左右端で完全一致させず、霧・柱・暗部を使って継ぎ目を隠す。
- チャンク順は遠征シードから決定し、セーブ復帰で同じ景色を再現できるようにする。

## 10. 灰市外縁・次工程の必要素材

次工程では一度に全区画を作らず、灰市外縁だけを以下の順で制作・確認する。

### Gate 1: 合成基準セット

1. `ash-sky-day`
2. `ash-cloud-a`
3. `ash-far-a`
4. `ash-mid-standard-a`
5. `ash-streetback-standard-a`
6. `ash-ground-standard-a`

この6枚だけで、地面と背景の画風、接地線、奥行きを実画面確認する。

### Gate 2: 道幅差分

1. `ash-mid-wide-a` / `ash-streetback-wide-a` / `ash-ground-wide-a`
2. `ash-mid-narrow-a` / `ash-streetback-narrow-a` / `ash-ground-narrow-a`

### Gate 3: 反復緩和

1. Far差分 `B`
2. Standard差分 `B`
3. Cloud差分 `B`

### Gate 4: 時間帯

1. `ash-sky-dusk`
2. `ash-sky-night`
3. `ash-window-lights`

### Gate 5: 小物・ランドマーク

各小物を個別PNGで制作し、レーンとPivotを定義してから導入する。
大型門は単独小物ではなく`Landmark`チャンク一式として制作する。

## 11. 受け入れ条件

- 地面だけ別画像に見えない。
- キャラの両足と影が道路面へ接地して見える。
- Wide / Standard / Narrowで道幅が変わってもキャラが上下しない。
- 小物が浮かず、隣の小物の断片も混ざらない。
- 空だけを時間帯で変更できる。
- 遠景、中景、地面を単独表示しても役割が分かる。
- 左右接続部が通常速度と2倍速の両方で目立たない。
- 30秒間見ても同じ塔・街灯の機械的反復が目立たない。
- 停止中は全移動レイヤーと小物が停止する。
- 1920x1080 Game Viewでキャラ、背景、HUDが競合しない。
