# Courier route prototype references

These images define the adopted direction for the role and expedition-system
prototype. They are not literal full-screen exports. Runtime implementation
must follow `docs/ui/specs/courier-route.md` and the repository UI rules.

- `system-production-reference-v1.png`: combined role, route and seal language.
- `route-ledger-background-study-v1.png`: background work surface used by the
  runtime route screen.
- `role-framework-reference-v1.png`: four base roles, two branches and one
  qualification-seal slot.
- `expedition-seal-card-reference-v1.png`: compact receipt and expanded postal
  exploration-seal treatment.

Character creation is explicitly out of scope. The game selects from authored
couriers.
